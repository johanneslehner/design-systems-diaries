## Projects

### Component Website
A modern React component library showcase built with **React**, **Material-UI (MUI)**, and **Tailwind CSS**, featuring a dynamic theme system powered by pure CSS custom properties.

**Location:** `component-website/`

**Features:**
- 🎨 Dynamic theme switching (Light/Dark)
- 🧩 MUI and Tailwind CSS components
- 💾 Theme persistence with localStorage
- ⚡ Fast development with Vite
- 📱 Fully responsive design

**Quick Start:**
```bash
cd component-website
npm install
npm run dev
```

See [component-website/README.md](component-website/README.md) for detailed documentation.
